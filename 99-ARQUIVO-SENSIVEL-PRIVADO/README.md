# Arquivo Sensível Privado

Esta pasta preserva anexos familiares identificáveis enviados por Sol Lima durante a formação do conceito do livro.

## Finalidade

Preservação e rastreabilidade. Os arquivos não constituem material aprovado para publicação.

## Proibições

- não publicar;
- não copiar para sites, redes sociais, anúncios ou apresentações;
- não inserir no livro;
- não inferir caráter, crença, saúde mental ou sofrimento pela aparência;
- não usar em modelos, testes visuais ou geração de novas imagens;
- não divulgar o nome, parentesco ou contexto das pessoas retratadas.

Qualquer uso futuro exige uma autorização nova, específica e registrada de Sol.
